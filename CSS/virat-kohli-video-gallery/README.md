# Virat Kohli Video Gallery

This is Assignment 2 from the Chai and Code course under the CSS topic.

The project contains a carousel at the top and three video cards in the middle, each containing a YouTube video and a Watch Now link.

The images used in the carousel are not perfect because I couldn't find images that fit the carousel properly.

At some points, I got stuck, so I took help from ChatGPT.

## Technologies Used

- HTML
- CSS
- Bootstrap

## Features

- Virat Kohli themed image carousel at the top
- Three video cards
- YouTube videos embedded in the cards
- Watch Now links for each video
- Responsive layout using Bootstrap and CSS
- Footer with copyright information
- Layout created using CSS Flexbox and Bootstrap
